# 🌾 GRAMIN GYAAN MARG (ग्रामीण ज्ञान मार्ग)
> Empowering Rural Youth Through Guided Education & Skill Development

**GRAMIN GYAAN MARG** is a digital platform designed specifically for rural students and youth in regions like Chhatarpur, Madhya Pradesh. It bridges the information gap by providing localized educational pathways, scholarship guidance, vocational training roadmaps, and career counseling in Hindi and local languages.

---

## 🌟 Key Features
* 🎓 **Localized Educational Roadmaps:** Step-by-step guidance for higher education and vocational courses post 10th/12th grade.
* 🏛️ **Government Scheme & Scholarship Tracker:** Filter and apply for state and central educational subsidies.
* 🗣️ **Multilingual & Offline Support:** Hindi-first UI designed for low-bandwidth rural mobile networks.
* 👨‍🏫 **Mentorship Connect:** Direct Q&A portal connecting rural students with university mentors and alumni.
* 📜 **Skill Assessment Modules:** Self-guided quizzes to discover career interests and skill gaps.

---

## 🛠️ Tech Stack
* **Frontend:** React.js / Vite, Tailwind CSS, Lucide React Icons
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / PostgreSQL
* **Authentication:** JWT / Firebase Auth
* **Deployment:** Vercel (Frontend), Render/Heroku (Backend)
